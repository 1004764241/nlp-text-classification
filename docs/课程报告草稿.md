## 摘要

随着电子商务的迅速发展，网络购物评论数据呈爆炸式增长，对评论文本进行自动分类具有重要的商业价值和研究意义。本文围绕中文商品评论的多类别自动分类任务展开研究，采用公开的 online\_shopping\_10\_cats 数据集，涵盖书籍、手机、平板、水果、洗发水、热水器、蒙牛、衣服、计算机和酒店共 10 个商品类别，约 6.2 万条真实评论。在技术路线上，采用 jieba 中文分词工具对原始文本进行预处理，结合 TF-IDF（词频-逆文档频率）算法将文本转化为高维稀疏向量表示，并分别使用线性支持向量机（LinearSVC）、多项式朴素贝叶斯（MultinomialNB）和逻辑回归（Logistic Regression）三种经典分类器进行建模与对比实验。实验结果表明，TF-IDF 结合 LinearSVC 的组合方案效果最佳，在测试集上取得了 89.23% 的分类准确率和 88.11% 的宏平均 F1 值，验证了传统机器学习方法在中文文本分类任务上的有效性。

**关键词**：中文文本分类；TF-IDF；支持向量机；朴素贝叶斯；逻辑回归；商品评论

## 一、选题背景

随着互联网购物平台的普及，淘宝、京东、美团等平台每天产生海量用户评论文本。这些评论蕴含着用户对商品品质、服务体验等方面的真实反馈，对商家运营决策、平台内容管理和消费者购买参考均具有重要价值。然而，人工逐条阅读和标注评论的方式效率低下，难以应对大规模数据的实时处理需求。

文本分类是自然语言处理（NLP）领域的基础任务之一，旨在将文本自动归入预定义类别。中文文本分类相比英文面临更多挑战：中文书写不以空格分词，需要专门的分词工具；中文存在大量同义词、歧义词和网络新词；评论文本口语化程度高，噪声较多。

本项目选取真实电商评论数据，构建一个覆盖 10 个商品类别的中文文本自动分类系统，探索传统机器学习方法在该任务上的性能表现，为后续引入深度学习方法提供基线参考。

## 二、相关工作介绍

文本分类研究历史悠久，主要经历了以下几个阶段：

**（1）基于规则的方法**：早期研究依赖人工构建的规则和词典进行分类，可解释性强但规则维护成本高，难以覆盖开放域文本。

**（2）基于统计机器学习的方法**：TF-IDF、词袋模型（Bag of Words）等特征提取方法配合朴素贝叶斯、支持向量机、逻辑回归等分类器，在新闻分类、垃圾邮件过滤等任务上取得了良好效果。Yang 等人（1999）系统比较了多种机器学习方法在文本分类上的表现，发现 SVM 和 kNN 整体表现最优。

**（3）基于深度学习的方法**：Kim（2014）提出的 TextCNN 利用卷积神经网络捕捉局部 n-gram 特征，Liu 等人提出的 TextRNN 则用循环神经网络建模序列依赖，均显著优于传统方法。

**（4）基于预训练语言模型的方法**：以 BERT（Devlin 等，2019）为代表的预训练语言模型在下游分类任务上取得了大幅领先的效果，成为当前主流方案。针对中文的 BERT-wwm（哈工大）、MacBERT（哈工大讯飞联合实验室）等模型进一步提升了中文任务表现。

本项目聚焦于传统机器学习方法，旨在通过完整的工程实现深入理解 TF-IDF 特征提取与经典分类器的原理，为后续引入深度学习方法提供对照基线。

### 3.2 数据预处理

#### 3.2.1 数据清洗

原始数据集包含约 62,774 条记录，经过以下清洗步骤后得到 62,605 条有效数据：

- 删除 `cat`（类别）或 `review`（评论）字段存在空值的记录（共 1 条）；
- 删除以类别+评论内容为键的重复记录（共 17 条）；
- 过滤评论文本长度小于 5 个字符的过短记录（共 151 条）。

#### 3.2.2 中文分词

中文文本以字符流形式书写，没有天然词边界，需要分词工具将句子切割为词元序列。本项目使用 **jieba** 分词库，采用精确模式（`cut_all=False`）进行分词。jieba 基于前缀词典和隐马尔可夫模型（HMM）实现中文分词，能较好地处理歧义词和未登录词。

核心分词代码如下：

```python
def tokenize(text: str, stopwords: set) -> str:
    import jieba
    tokens = jieba.cut(text, cut_all=False)
    filtered = [t for t in tokens if t.strip() and t not in stopwords]
    return " ".join(filtered)
```

分词后，每条评论被转化为以空格分隔的词元字符串，例如：

> 原文：`这款手机信号很差，非常失望`  
> 分词：`这款 手机 信号 很 差 ， 非常 失望`

#### 3.2.3 数据集划分

采用分层抽样（stratified split）将数据按 8:1:1 的比例划分为训练集、验证集和测试集，保证各类别在三个子集中的分布比例一致：

| 子集 | 样本数 |
|------|--------|
| 训练集 | 50,083 |
| 验证集 | 6,261 |
| 测试集 | 6,261 |

### 3.3 TF-IDF 特征提取

#### 3.3.1 基本原理

TF-IDF（Term Frequency–Inverse Document Frequency）是信息检索中最经典的文本向量化方法，其核心思想为：**一个词在某文档中出现频率越高、在整个语料库中出现频率越低，则该词对该文档的区分度越强。**

对于词 $t$ 在文档 $d$ 中的 TF-IDF 值计算如下：

$$\text{TF-IDF}(t, d) = \text{TF}(t, d) \times \text{IDF}(t)$$

其中词频项（使用次线性平滑，`sublinear_tf=True`）为：

$$\text{TF}(t, d) = 1 + \log(\text{count}(t, d))$$

逆文档频率为：

$$\text{IDF}(t) = \log\frac{1 + N}{1 + \text{df}(t)} + 1$$

式中 $N$ 为语料库文档总数，$\text{df}(t)$ 为包含词 $t$ 的文档数量。最终对每篇文档的 TF-IDF 向量做 L2 归一化，消除文档长度的影响。

#### 3.3.2 二元语法（Bigram）

除单个词（Unigram）外，本项目还纳入相邻两词构成的词对（Bigram）作为特征，即将 `ngram_range` 设为 `(1, 2)`。Bigram 能捕捉局部语序信息，例如"非常 满意"、"质量 差"等短语组合往往比单个词具有更强的类别判别力。

词表规模设置为 `max_features=50000`，按 TF-IDF 权重从高到低保留最具区分力的 5 万个特征词（包含 Bigram）。

#### 3.3.3 实现

使用 scikit-learn 的 `TfidfVectorizer` 实现，主要参数如下：

```python
from sklearn.feature_extraction.text import TfidfVectorizer

tfidf = TfidfVectorizer(
    analyzer="word",
    token_pattern=r"\S+",    # 以空白符切分，支持中文词元
    max_features=50000,
    ngram_range=(1, 2),
    sublinear_tf=True,        # 使用 1+log(tf) 平滑
    min_df=2,                 # 词频过低（<2篇文档）的词元剔除
    max_df=0.95,              # 出现在95%以上文档中的词视为停用词剔除
)
```

### 3.4 分类模型

本项目基于 `sklearn.pipeline.Pipeline` 将 TF-IDF 向量化器与分类器封装为统一的流水线，便于训练和推理。

#### 3.4.1 线性支持向量机（LinearSVC）

**原理**：SVM 的目标是寻找一个超平面，使得不同类别的样本之间的间隔（margin）最大化。对于线性不可分问题，引入松弛变量允许部分样本越界，通过正则化参数 $C$ 控制间隔宽度与误分类惩罚之间的权衡：

$$\min_{w,b,\xi} \frac{1}{2}\|w\|^2 + C\sum_{i}\xi_i$$
$$\text{s.t.} \quad y_i(w \cdot x_i + b) \geq 1 - \xi_i, \quad \xi_i \geq 0$$

对于多分类任务采用 One-vs-Rest（OvR）策略，为每个类别训练一个二分类器，最终取置信度最高的类别作为预测结果。LinearSVC 针对线性核进行了优化，时间复杂度远低于核 SVM，适合高维稀疏文本特征。

**关键代码**：

```python
from sklearn.svm import LinearSVC
from sklearn.pipeline import Pipeline

pipeline = Pipeline([
    ("tfidf", TfidfVectorizer(...)),
    ("clf", LinearSVC(C=1.0, max_iter=2000, random_state=42)),
])
pipeline.fit(X_train, y_train)
```

#### 3.4.2 多项式朴素贝叶斯（MultinomialNB）

**原理**：朴素贝叶斯基于贝叶斯定理，假设各特征（词）在给定类别下条件独立：

$$P(y \mid x_1, \ldots, x_n) \propto P(y) \prod_{i=1}^{n} P(x_i \mid y)$$

MultinomialNB 适用于词频计数特征，对文本分类具有较好的效果，训练和预测速度极快。通过拉普拉斯平滑参数 $\alpha$ 处理零概率问题：

$$P(x_i \mid y) = \frac{\text{count}(x_i, y) + \alpha}{\sum_j \text{count}(x_j, y) + \alpha \cdot |V|}$$

#### 3.4.3 逻辑回归（Logistic Regression）

**原理**：逻辑回归通过 Softmax 函数对多分类后验概率建模：

$$P(y=k \mid x) = \frac{e^{w_k \cdot x}}{\sum_{j} e^{w_j \cdot x}}$$

使用最大似然估计（MLE）加 L2 正则化训练模型参数，采用 `lbfgs` 优化器。逻辑回归的优点是可输出概率估计，便于设置置信度阈值。

### 3.5 模型评估

采用以下指标进行综合评估：

- **Accuracy**：整体准确率，即预测正确样本占总样本的比例；
- **Precision / Recall / F1**：各类别的精确率、召回率及调和均值；
- **Macro-F1**：各类别 F1 的简单平均，对样本不均衡敏感，反映模型对少数类的处理能力；
- **Weighted-F1**：按各类别支持数加权平均，受类别分布影响较大。

### 5.3 结果分析

**（1）整体表现良好**：TF-IDF + LinearSVC 方案在 10 分类任务上取得 89.23% 的准确率，表明传统机器学习方法在商品评论分类任务上具备实用价值，不依赖 GPU 即可完成训练（训练耗时约 7.6 秒）。

**（2）蒙牛类别识别近乎完美（F1=1.00）**：蒙牛属于乳制品品牌，其评论文本词汇特征（如"牛奶"、"蒙牛"、"乳"等）与其他类别区分度极高，TF-IDF 能有效捕捉这些强区分性词汇。

**（3）酒店和书籍类别效果较好（F1≥0.956）**：酒店评论包含"入住"、"前台"、"房间"等高频领域词汇；书籍评论涉及"作者"、"章节"、"阅读"等特有词汇，均与其他类别存在明显的词汇边界。

**（4）热水器类别召回率偏低（Recall=0.444，F1=0.600）**：原因主要有两点：其一，热水器训练样本极少（435条），占总训练集的0.87%，严重的类别不均衡导致分类器对该类别学习不足；其二，热水器评论词汇与计算机、平板等家电类目存在一定重叠。后续可通过上采样（SMOTE）或调整类别权重（`class_weight='balanced'`）缓解该问题。

**（5）平板与洗发水存在一定混淆**：平板、手机、计算机同属数码产品，评论中均包含"屏幕"、"性能"、"系统"等词，存在词汇特征重叠；洗发水与衣服均为消费品，评论风格相似，容易混淆。这也反映了仅依赖词袋特征无法完全捕捉语义信息的局限性。

## 七、小结

本项目以中文商品评论多分类为研究对象，系统实现了从原始数据清洗、jieba 分词、TF-IDF 特征提取到分类器训练与评估的完整流程。实验结果表明，TF-IDF + LinearSVC 方案在 10 分类任务上取得了 89.23% 的准确率和 88.11% 的宏平均 F1，对大多数类别具有良好的区分能力，蒙牛、酒店、书籍等类别 F1 均超过 0.95。

不足之处主要体现在两点：一是类别不均衡问题（热水器仅有 54 条测试样本）导致少数类召回率偏低；二是 TF-IDF 属于词袋模型，忽略词序和语义信息，对于平板、手机、计算机等语义相近类别的区分存在局限。

后续工作可从以下方向改进：引入停用词过滤进一步净化特征空间；利用预训练词向量（Word2Vec、fastText）或句向量（BERT）替代 TF-IDF 以引入语义信息；针对不均衡类别采用数据增强或代价敏感学习策略。

### 切换模型

编辑 `configs/default.yaml` 中的 `train.model_type` 字段：

```yaml
train:
  model_type: "tfidf_svm"   # 可选: tfidf_nb | tfidf_svm | tfidf_lr
```
